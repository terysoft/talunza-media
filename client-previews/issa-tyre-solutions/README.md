## Production migration checklist
1. Replace the preview banner if desired.
2. Change `<meta name="robots" content="noindex,nofollow">` to `index,follow`.
3. Deploy the same `index.html` at the web root for `www.its.co.zw`.
4. Add the real official ISSA logo and approved real shop/workshop photos when available.
5. Verify current opening hours, map pin/landmark, services and contact ownership before publishing.
6. Add analytics and Search Console after the domain deployment.
7. Keep stock and prices WhatsApp-led unless ISSA commits to maintaining live inventory on the website.

The site is dependency-free and can be hosted by Nginx, Caddy, Apache, GitHub Pages, Cloudflare Pages, Netlify, Vercel static hosting, or any basic static host.
