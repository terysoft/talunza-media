# Talunza Media

Talunza Media is the media, AI production and practical education arm of Talunza.

## Commercial pillars

1. **Media Production** — photography, weddings, events, adverts, interviews, music videos, drama and documentary production.
2. **AI Studio** — AI-assisted film, graphics, music, storyboarding, VFX, post-production and commercial content.
3. **Academy** — practical, income-focused training in AI creative tools, content production, graphics, websites, agent-assisted software development and validated digital hustles.

## Operating principle

Learn by producing real work. Sell only capabilities we can repeatedly deliver well. Use every project to build portfolio evidence, production workflows, reusable prompts, SOPs and relationships that strengthen the wider Talunza distribution network.

## Website objective

The public website will:
- show real portfolio work;
- explain production and AI services;
- publish practical training offers;
- capture enquiries and bookings;
- turn media relationships into a wider Talunza distribution network;
- cross-refer suitable customers to Talunza technical services and software without making the media brand feel like an advert for unrelated products.

## Build status

Repository initialized. Website implementation follows evidence-first: initial service architecture and portfolio framework first; real founder work replaces placeholders as it is produced.
